# 🎂 Deep Birthday Event Bot

An interactive Telegram birthday celebration bot built with Python & Pyrogram.

Turn a simple birthday wish into a cinematic Telegram event with:

- 🎂 Interactive Cake Cutting
- 🎁 Legendary Gift Reveal
- 🎆 Fireworks Animation
- 👑 Birthday King Protection
- 🎬 Event-Based Flow
- ⚡ Typewriter Effects
- 🎮 Inline Button Interactions

---

# ✨ Features

🎂 Only the birthday person can cut the cake

🎁 Interactive gift opening system

🎆 Animated fireworks sequence

👑 Birthday King access control

⚡ Telegram message animation effects

🎬 Event-style celebration flow

🚀 Easy to customize

```
```

```
API_ID=
API_HASH=
BOT_TOKEN=

```

```bash
python main.py
```
